Install Crystal Front

Добавь игру на главный экран телефона и запускай её по прямой ссылке.

Android Chrome: нажми Add to phone. Если системное окно не появится, открой меню браузера и выбери Add to Home screen или Install app. iPhone Safari: Share → Add to Home Screen.
Нажми Add to phone. Если браузер поддерживает установку веб-приложений, появится системное предложение добавить Crystal Front на экран.
