Как играть

Клавиатура и мышь или телефон в горизонтальном положении. Прогресс сохраняется только в этом браузере. Для загрузки игры нужен интернет; офлайн-игра не гарантируется.

Phone install

Install Clutter Cup

Добавь ярлык игры на главный экран телефона. На Android Chrome кнопка может открыть системное окно установки.

Если браузер не откроет окно установки: Android Chrome — меню браузера → Add to Home screen / Install app. iPhone Safari — Share → Add to Home Screen.
